# Proyecto_AlquiTech
Repositorio AlquiTech

Versión 0.1: frontend con el diseño real (HTML, CSS y JavaScript).

## Qué incluye
- 6 páginas: inicio, registro, login, inmuebles, panel del propietario y panel del inquilino.
- Estilos con la guía de estilo definitiva (Montserrat y Lato, paleta de menta y turquesa).
- Diseño adaptable a móvil y tablet.
- Validación de los formularios de registro y login con JavaScript.

## Qué falta
- Conexión con el backend y la base de datos.
- El resto de páginas (detalle de inmueble, contratos, pagos, incidencias...).
- La caja "Vistas de demo" es provisional y se quitará cuando el login lleve a cada panel.

## Cómo verlo
Abrir `HTML/index.html` en el navegador.
